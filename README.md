# MCRANCKED

Static Minecraft PvP tier-list website.

## Files
- `index.html` — homepage
- `rankings.html` — public rankings
- `app.js` — main rendering/functionality; keep this file unchanged
- `players.js` — player database generated by Admin Panel
- `icons.js` — mode icon URLs
- `admin.html` — private admin panel
- `styles.css` — website styling

## Updating players
1. Open `admin.html`.
2. Login with the configured admin password.
3. Add or edit a player.
4. For every gamemode choose `Not Tested` if the player has not been tested. Untested modes show an empty dashed circle and a blank placeholder instead of a logo/tier.
5. Click **Download players.js**.
6. Replace ONLY the website's old `players.js` with the downloaded file.
7. Do not replace `app.js`.

Overall points and positions are calculated automatically from the tested gamemode points.


## Custom Logo
Open `site-config.js` and replace `PASTE_YOUR_TIERLIST_LOGO_LINK_HERE` with your tier-list logo's direct image URL. No other code needs to be changed.
